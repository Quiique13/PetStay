PetStay 1.7.1 adds reservation cancellation and prepares the app's privacy information.

- Cancel an individual reservation from Reservations, Payments or the reservation editor. Confirmation identifies the saved reservation; dismissing it preserves unsaved edits.
- Guest photos load directly from the selected file. Unreadable images show a clear message and allow choosing another photo. Photo errors no longer suggest changing prices.
- Public, script-free pages describe PetStay, privacy, terms of use, cookies/local storage and data-rights requests. Links are available before sign-in and inside the app.
- Legal pages identify Henrique Costa Coutinho as the individual operator and provide the supplied privacy/support email. They remain clearly marked as drafts pending the remaining contact, hosting and retention details. This release does not represent completed GDPR compliance or Google verification.

### Windows update

Close PetStay before updating. For the portable version, put the new executable beside the existing `data/` folder and preserve that folder. The installer preserves application data. Sign in with the same account to use the synchronized hotel.

Windows downloads are unsigned. `SHA256SUMS.txt` lists the portable and installer checksums. No hotel records, private credentials or local backups are included.

### Web app

The web version is updated at https://quiique13.github.io/PetStay/ after the Pages workflow succeeds. Reopen the installed web app and accept its update notification when offered.

The Android debug APK remains available in release 1.7.0; this release updates the web app and Windows downloads.
